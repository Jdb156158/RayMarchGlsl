# RayMarchGlsl

用 WebGL 2 / GLSL 实时复刻 [Jaenam97 的 Badge Tech 视频](https://x.com/Jaenam97/status/2104201809132990900) 中的蓝色六边形珐琅徽章与悬停分层效果。

**在线体验：[https://jdb156158.github.io/RayMarchGlsl/](https://jdb156158.github.io/RayMarchGlsl/)**

## 效果

- 五层可分离材质：晶体保护层、银色线框、全息箔膜、蓝色珐琅和金属底板。
- 鼠标驱动的三维旋转、实时反射、虹彩色散和 GGX 金属高光。
- 展开时显示跟随各层旋转的六边形虚线框与 01–05 编号。
- 第一层采用中央隆起的晶体透镜造型，包含边缘折射、珍珠高光和彩色光纹。
- 支持桌面鼠标、触屏、键盘操作及减少动态效果设置。

## 运行

无依赖、无需构建。在项目目录运行：

```sh
python3 -m http.server 4188 --bind 127.0.0.1
```

打开 [http://127.0.0.1:4188](http://127.0.0.1:4188)。也可以直接用支持 WebGL 2 的浏览器打开 `index.html`。

## 操作

- 悬停徽章：展开五层材质；移开鼠标：合拢。
- 移动鼠标：改变观察角度和反光。
- 「展开图层」按钮：保持展开；滑杆：调整分离程度。
- 手机点击徽章：展开或合拢。
- 暂停按钮：暂停自动材质变化；重置按钮：恢复视角与合拢状态。
- 键盘聚焦画布后，方向键调整视角，空格或 Enter 展开图层。

## 实现

原生 JavaScript + WebGL 2 / GLSL ES 3.0。形状使用 SDF raymarching，反射使用程序化灯光环境与 GGX 高光，虹彩与晶体边缘色散是视觉近似。所有图案、材质、编号和虚线框均实时生成，无图片贴图、三维模型、框架或视频依赖。

这是根据视频独立实现的效果复刻，不是作者原始着色器；晶体透射采用薄层近似，不包含完整多次折射。页面适配触屏与减少动态效果设置，渲染分辨率有限制以控制 GPU 开销。
